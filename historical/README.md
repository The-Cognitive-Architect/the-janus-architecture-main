# Historical Materials

This directory contains earlier project records retained as part of the development history of The Janus Machine.

- **[communications/](communications/):** the December 2025 and January 2026 public messages, kept with their original wording and dates.
- **[resonance-chamber/](resonance-chamber/):** the early FSI/OMEF Python proof-of-concept, together with its Apache 2.0 license and notice.
- **[repository/](repository/):** previous README, dated roadmap, and old repository changelog.

The current project overview is the [main README](../README.md), while the early hardware architecture and working notes are under [development/](../development/).
